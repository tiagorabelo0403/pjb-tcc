ANTIPADRÕES TERMINANTEMENTE PROIBIDOS


THREAD POOL SATURADO
- Nunca ThreadPoolExecutor fora da governança do PjbExecutionOrchestrator
- Nunca @Async sem pool configurado e reject policy explícita
- Nunca synchronized em seção crítica longa em Virtual Thread
  (usar ReentrantLock ou StampedLock)

CODED FUTURES SOLTOS
- Nunca CompletableFuture.supplyAsync() sem executor explícito
- Nunca .get() sem timeout  thread starvation silenciosa
- Nunca misturar CompletableFuture com Virtual Threads sem Structured Concurrency

CONNECTION POOL
- Nunca I/O pesado dentro de @Transactional longa
- Nunca N+1 queries  fetch join ou projeção explícita obrigatório
- Nunca reter conexão durante chamada HTTP externa

MEMORY LEAK SILENCIOSO
- Nunca ThreadLocal sem remove() em finally
- Nunca lista/map sem bound em cache local de ApplicationService
- Nunca referência de sessão HTTP fora do request scope
- Caffeine com TTL para qualquer cache de suporte

RACE CONDITION
- Nunca HashMap em contexto compartilhado  ConcurrentHashMap obrigatório
- Toda atualização de estado compartilhado via AtomicReference ou SELECT FOR UPDATE

EXECUÇÃO BLOQUEANTE
- Nunca chamada HTTP síncrona dentro de request HTTP principal
- Nunca polling em loop fechado sem backoff exponencial
- Timeout explícito em toda integração externa

REGRAS TÉCNICAS INVIOLÁVEIS


CONCORRÊNCIA
- Toda execução assíncrona passa pelo PjbExecutionOrchestrator
- Virtual Threads via PjbVirtualThreadSpine  nunca criar nova fábrica
- Structured Concurrency para operações com múltiplos ritos em paralelo
- Scoped Values para contexto sigiloso entre threads

INJEÇÃO DE DEPENDÊNCIA
- Construtor público único  zero @Autowired em fields
- Zero Lombok em camadas críticas

TRANSAÇÕES
- @Transactional apenas em ApplicationService
- Budgets via PjbTransactionalExecutionSupport
- Zero I/O externo dentro de @Transactional
- Outbox para efeitos pós-commit

LGPD / SIGILO MILITAR
- MemoryAccessPolicy antes de toda operação externa
- Sigiloso/Crítico: NUNCA enviado a qualquer serviço externo
- Bind/restore em toda operação assíncrona
- Zero log de conteúdo sigiloso

RESILIÊNCIA
- Circuit breaker Resilience4j em toda integração externa
- Bulkhead para limitar chamadas simultâneas
- Retry com backoff exponencial
- Fallback gracioso em toda dependência opcional
- Timeout explícito em toda chamada externa
