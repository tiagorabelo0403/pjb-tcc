# Features

Documentação funcional agrupada por domínio.

Este diretório deve guardar material funcional e estável. Evidência operacional por rodada,
refactors e marcos históricos ficam em `docs/evolution/` para evitar mistura entre especificação
e histórico.

## Mapa

- `advogado-office/` — escritório, afiliação e operação profissional
- `consulta-publica/` — busca, páginas públicas e regras de exposição
- `institutional-workbench/` — visão funcional consolidada do workbench institucional
- `magistratura/` — visão funcional consolidada da magistratura
- `protocol/` — visão funcional consolidada de protocolo e peticionamento

## Regra de organização

- documentos evergreen ficam em `docs/features/`
- documentos `*_ROUND*.md` ficam em `docs/evolution/`
- README de cada domínio aponta para os históricos relevantes
